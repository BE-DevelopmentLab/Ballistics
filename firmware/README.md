# Celestial firmware

- `core/`: Solstice's solver and Bluetooth packets (`ballistics.h`, `drag_tables.h`, `protocol.h`), a copy of the
  Solstice folder's `core/` as of 2026-11-15. Meridian builds against it unchanged. The Solstice firmware itself
  lives on the laptop (`ballistic-calc/`); keep this copy in step with it.
- `meridian/`: firmware for Meridian, the rifle-mounted unit. Start with `meridian/CLAUDE.md`.
